# Suma

![demo_3](/screenshots/demo_3.png)
![demo_3](/screenshots/demo_5.png)

Suma is a desktop tool for generating structured, machine-readable Markdown summaries of academic research papers in PDF format. It uses Google Gemini models to analyze the content and produce detailed summaries with sections for title, authors, publication year, context, objectives, methods, results, conclusions, limitations, and future work. Suma is designed for accuracy, completeness, and ease of use, helping researchers and students quickly extract key information from scientific papers.

To use Suma, open the application, provide your Google Gemini API key, and drag and drop your PDF files. The app processes each file and saves the generated summary in a Markdown file alongside the original PDF. You can review, copy, or edit the summaries within the app.

Suma is built with Tauri and React, providing a fast and native experience on your desktop.
